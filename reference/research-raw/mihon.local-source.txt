tabindex="-1" data-v-9916ce12>Local source <a class="header-anchor" href="#local-source" aria-label="Permalink to &quot;Local source&quot;" data-v-9916ce12>​</a></h1><p data-v-9916ce12>If you like to download and organize your media, then you want to know how to manage your own series in Mihon.</p><div class="warning custom-block" data-v-9916ce12><p class="custom-block-title" data-v-9916ce12>WARNING</p><p data-v-9916ce12>This page explores some advanced features.</p></div><h2 id="creating-local-series" tabindex="-1" data-v-9916ce12>Creating local series <a class="header-anchor" href="#creating-local-series" aria-label="Permalink to &quot;Creating local series&quot;" data-v-9916ce12>​</a></h2><ol data-v-9916ce12><li data-v-9916ce12><p data-v-9916ce12>In the location you specified as your storage location (e.g., <code data-v-9916ce12>/Mihon/</code>), there should be a <code data-v-9916ce12>local</code> folder. Place correctly structured series inside that (e.g. <code data-v-9916ce12>/Mihon/local/</code>).</p><blockquote data-v-9916ce12><p data-v-9916ce12>If adding series in folders it is recommended to add a file named <code data-v-9916ce12>.nomedia</code> to the local folder so images do not show up in the gallery.</p></blockquote></li><li data-v-9916ce12><p data-v-9916ce12>You should now be able to access the series in <span class="shortcode navigation main_browse" data-v-9916ce12><svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" data-v-9916ce12><path d="M7,17L10.2,10.2L17,7L13.8,13.8L7,17M12,11.1A0.9,0.9 0 0,0 11.1,12A0.9,0.9 0 0,0 12,12.9A0.9,0.9 0 0,0 12.9,12A0.9,0.9 0 0,0 12,11.1M12,2A10,10 0 0,1 22,12A10,10 0 0,1 12,22A10,10 0 0,1 2,12A10,10 0 0,1 12,2M12,4A8,8 0 0,0 4,12A8,8 0 0,0 12,20A8,8 0 0,0 20,12A8,8 0 0,0 12,4Z" data-v-9916ce12></path></svg><span class="name" data-v-9916ce12>Browse</span></span> -&gt; <span class="shortcode navigation sources" data-v-9916ce12><span class="name" data-v-9916ce12>Sources</span></span> under <strong data-v-9916ce12>Local source</strong>.</p></li></ol><p data-v-9916ce12>If you add more chapters then you&#39;ll have to manually refresh the chapter list (by pulling down the list).</p><p data-v-9916ce12>Supported chapter formats are folders with pictures inside (such as <code data-v-9916ce12>.jpg</code>, <code data-v-9916ce12>.png</code>, etc) or archive files (<code data-v-9916ce12>ZIP</code>/<code data-v-9916ce12>CBZ</code>, <code data-v-9916ce12>RAR</code>/<code data-v-9916ce12>CBR</code>, and <code data-v-9916ce12>EPUB</code>). But expect better performance with directories and <code data-v-9916ce12>ZIP</code>/<code data-v-9916ce12>CBZ</code>.</p><p data-v-9916ce12>Note that a single folder or archive file is treated as a single chapter. For example, Mihon will not automatically split an <code data-v-9916ce12>EPUB</code> file containing multiple chapters into separate chapters within the app.</p><h3 id="folder-structure" tabindex="-1" data-v-9916ce12>Folder structure <a class="header-anchor" href="#folder-structure" aria-label="Permalink to &quot;Folder structure&quot;" data-v-9916ce12>​</a></h3><p data-v-9916ce12>Mihon requires a specific folder structure for local series to be correctly processed. Local series will be read from the <code data-v-9916ce12>local</code> folder. Each series must have a <code data-v-9916ce12>Series</code> folder and a <code data-v-9916ce12>Chapter</code> folder. Images will then go into the chapter folder. See below for more information on archive files. The path to the folder with images must contain both the series title and the chapter name (as seen above).</p><p data-v-9916ce12>Note that this is the same folder structure used by downloads of non-local sources. However, the filename format is not required to be the same; for example, Mihon adds a disambiguating hash based on the chapter URL when downloading chapters, but you do not need to do this.</p><h3 id="archive-files" tabindex="-1" data-v-9916ce12>Archive files <a class="header-anchor" href="#archive-files" aria-label="Permalink to &quot;Archive files&quot;" data-v-9916ce12>​</a></h3><p data-v-9916ce12>Archive files such as <code data-v-9916ce12>ZIP</code>/<code data-v-9916ce12>CBZ</code> are supported but the folder structure inside is not. Any folders inside the archive file are ignored. You must place the archive inside the <code data-v-9916ce12>Series</code> folder where the name will become the <code data-v-9916ce12>Chapter</code> title. All images inside the archive regardless of folder structure will become pages for that chapter.</p><h4 id="example-archives" tabindex="-1" data-v-9916ce12>Example <a class="header-anchor"
