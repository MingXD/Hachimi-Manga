Purpose and Scope 
 This document describes Foliate's preferences and settings system, including the GSettings schema hierarchy, settings persistence, the View Preferences window UI, and the binding mechanisms that synchronize settings between storage and UI components. 
 For information about the library view preferences (grid/list mode, cover display), see Book Collection Management . For navigation and progress tracking settings, see Navigation and Progress Tracking . 
 GSettings Schema Architecture 
 Foliate uses GSettings for persistent storage of user preferences and application state. The schema is hierarchically organized with a main schema and multiple child schemas.

 View Settings Schema Details 
 The viewer.view schema controls the appearance and behavior of the book rendering: 
 Paragraph and Typography Settings 
Key Type Default Description line-height double 1.5 Line spacing multiplier justify boolean true Full text justification hyphenate boolean true Automatic hyphenation 
 Layout and Page Settings 
Key Type Default Description gap double 0.06 Margin size as fraction of viewport max-inline-size uint 720 Maximum column width (horizontal) or height (vertical) in pixels max-block-size uint 1440 Maximum height (horizontal) or width (vertical) in pixels max-column-count uint 2 Maximum number of columns to display 
 Display and Behavior Settings 
Key Type Default Description brightness double 1.0 Display brightness multiplier scrolled boolean false Enable scrolled mode vs. paginated animated boolean true Enable page turn animations invert boolean false Invert colors in dark mode theme string 'default' Color theme name autohide-cursor boolean false Auto-hide cursor when reading override-font boolean false Override publisher-specified fonts

 View Preferences Window 
 The FoliateViewPreferencesWindow class provides a comprehensive UI for adjusting reading preferences. It extends AdwPreferencesDialog and is organized into four tabbed pages. 
 Window Structure 
Sources: src/ui/view-preferences-window.ui 1-261 
 Font Page Controls 
 The Font page provides three preference groups: 
Font Size : Controls for default and minimum font sizes using AdwSpinRow widgets with adjustments ranging from 1-72 points. 
Font Family : 
default-font AdwComboRow : Choose between Serif and Sans-serif as the default font family 
 override-font GtkSwitch : Toggle to override publisher-specified fonts 
Font Selection : Three GtkFontButton widgets for selecting specific font families: 
serif-font : Serif font family picker 
 sans-serif-font : Sans-serif font family picker 
 monospace-font : Monospace font family picker 
All font buttons use level="family" and use-font="true" properties. 
 Sources: src/ui/view-preferences-window.ui 3-110 
 Layout Page Controls 
 The Layout page is divided into two groups: 
 Paragraph Group: 
line-height AdwSpinRow : Range 1.0-3.0 with 0.05 increments, 2 decimal places 
 justify GtkSwitch : Enable full text justification 
 hyphenate GtkSwitch : Enable automatic hyphenation 
Page Group: 
gap AdwSpinRow : Margin size, range 0.0-0.5 with 0.01 increments, 2 decimal places 
 max-column-count AdwSpinRow : Range 1-10 columns 
 max-inline-size AdwSpinRow : Range 100-5000 pixels, step 60, with subtitle explaining it controls column width (horizontal) or height (vertical writing) 
 max-block-size AdwSpinRow : Range 100-5000 pixels, step 60, with subtitle explaining it controls height (horizontal) or width (vertical writing)

 Color and Behavior Pages 
 Color Page: 
Contains a GtkFlowBox ( theme-flow-box ) with theme selection controls. The flow box is configured with: 
selection-mode="none" 
 homogeneous="True" 
 row-spacing="12" and column-spacing="12" 
 CSS class theme-container 
The actual theme items are populated dynamically at runtime. 
 Behavior Page: 
Contains a single preference for reducing animations: 
reduce-animation GtkSwitch : Corresponds to the inverse of the animated GSettings key

 Color Scheme Settings 
 The color scheme is stored in the main GSettings schema and synchronized with Adw.StyleManager : 
Initialization : On startup, the application reads color-scheme from GSettings and applies it to StyleManager 
 Synchronization : When StyleManager.color_scheme changes, it's written back to GSettings 
 CSS Class Management : Windows add/remove the is-dark CSS class based on StyleManager.dark property
