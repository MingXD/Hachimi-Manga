This document details the viewer implementations and configuration components that handle manga page display in the Mihon reader. These components provide the core display functionality for different reading modes including vertical scrolling (webtoon) and page-by-page (pager) viewing. 
 For information about page loading mechanisms, see Page Loading and Image Processing . For reader settings and preferences, see Reader Configuration and Preferences . 
 Viewer Architecture Overview 
 The reader system implements multiple viewing strategies through a common Viewer interface, with each implementation optimized for different manga formats and reading preferences.

 WebtoonViewer Implementation 
 The WebtoonViewer provides continuous vertical scrolling for webtoon-style manga using a RecyclerView with a custom WebtoonLayoutManager . This viewer is optimized for long-strip format content. 
 WebtoonViewer Components 
The WebtoonViewer handles several key responsibilities: 
 Scroll Management : Uses a scrollDistance calculated as 3/4 of screen height for tap-based navigation app/src/main/java/eu/kanade/tachiyomi/ui/reader/viewer/webtoon/WebtoonViewer.kt 53 Scroll events trigger menu hiding when scroll velocity exceeds the readerHideThreshold app/src/main/java/eu/kanade/tachiyomi/ui/reader/viewer/webtoon/WebtoonViewer.kt 94-96 
 Chapter Preloading : Monitors scroll position to request preloading of adjacent chapters. When scrolling up and reaching a ChapterTransition.Prev , it requests preload of the previous chapter app/src/main/java/eu/kanade/tachiyomi/ui/reader/viewer/webtoon/WebtoonViewer.kt 98-104

 PagerViewer Implementation 
 The PagerViewer serves as an abstract base for page-by-page viewing implementations (L2R, R2L, and Vertical), using a ViewPager to display individual pages. 
 PagerViewer State Management
