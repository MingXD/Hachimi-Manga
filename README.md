# MangaAgent — 本地漫画阅读器

> 状态：**调研与方案设计阶段**（尚未开始编码）。本仓库是设计决策与开发资料的唯一来源。

## 项目定位
- 平台：**Windows 优先**，未来考虑 iOS/Android
- 核心场景：**日本漫画阅读**（右到左），高度可定制的阅读体验
- 能力范围：本地漫画阅读 + 本地文件管理（整理、重命名、元数据）
