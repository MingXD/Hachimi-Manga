## 0. 目标（用户需求）
5. **以文件夹层级展示所有漫画**：不扁平化，按目录树浏览
6. **文件操作**：复制、移动、重命名、删除等

## 1. 层级库视图（文件夹树 + 内容区）

### 布局
```
主窗口
├── 侧边栏（可切换）
│   ├── [视图A] 文件夹树（TreeView）：库根 → 子目录 → 书
│   └── [视图B] 系列聚合（元数据驱动，后续）
├── 内容区：当前选中文件夹的 封面墙 / 列表
└── 顶栏：视图切换、搜索、排序、添加库
```

### 文件夹树（视图A，默认）
- **TreeView**：每个库根一个顶级节点 → 子目录逐级展开 → 叶子 = 书（CBZ/文件夹书）
- 展开状态记忆；当前选中文件夹 → 右侧显示该文件夹内的书（封面墙）
- 文件夹内同时含子目录和书 → 都显示（书在封面墙，子目录可在树中继续展开；也可在封面墙里以"文件夹卡片"显示子目录【可选】）
- 参考 CDisplayEx：树浏览文件夹找漫画，双击进书
- 数据来源：现有 LibraryScanner（递归扫描），改为保留目录树结构（不再扁平化为 Books 列表）

### 与现有扁平封面墙的关系
- **两种视图可切换**：层级树（默认，满足需求5）/ 扁平封面墙（现有，按系列聚合）
- 搜索/排序在两种视图都可用

### 性能
- 树懒加载（展开时加载子目录，不一次性展开全库）
- 封面墙懒加载（复用现有滚动按需加载）

## 2. 文件操作（右键菜单 + 快捷键）

### 操作清单（选中书 / 文件夹 / 多选）
| 操作 | 说明 | 参考 |
|---|---|---|
| 打开 | 进入阅读器（双击同） | 现有 |
| 在资源管理器中显示 | ShellExecute 打开所在文件夹 | Windows 惯例 |
| **重命名** | 内联编辑（F2）；书籍自动同步显示名 | Calibre/ComicRack |
| **移动 / 复制** | 对话框选择目标文件夹；移动可跨库；复制保留原文件 | Calibre 库操作 |
| **删除** | 移入回收站（非永久删除），可恢复 | Windows 惯例 |
| 属性 | 路径/大小/页数/修改时间 | 系统惯例 |

### 多选
- 封面墙支持多选（Ctrl/Shift），批量操作（重命名/移动/删除）

### 可撤销（延续 M2 设计）
- **移动/重命名**：执行前记录"操作日志"（原路径→新路径），可一键撤销（移回）
- **删除**：走回收站（天然可恢复），不提供软件内撤销
- 复制：无需撤销（原文件不动）

### 与库索引同步
- 文件操作后：更新 SQLite 索引（LibraryDb 增删改）；阅读进度按路径重定位（已有设计：路径+修改时间）

## 3. 实现要点
- **TreeView**（Avalonia 原生控件）：`ItemsSource` 绑定目录树模型（FolderNode{ Name, Path, Children, Books }）
- 扫描改造：LibraryScanner 返回**目录树**（而非扁平 List<BookInfo>）；扁平视图由树展平生成
- **文件操作服务**：`FileManagerService`（Core 层）：Rename/Move/Copy/DeleteToRecycleBin + 操作日志（Undo）
- 右键菜单：`ContextMenu` + 命令绑定；回收站删除用 `Shell32 SHFileOperation` 或 `Microsoft.VisualBasic.FileIO.FileSystem.DeleteFile(..., RecycleOption)`
- 库索引更新：操作完成后触发增量重扫（或定向更新）
