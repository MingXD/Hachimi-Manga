## 决策记录

### D1 技术栈 ✅
- 选择：**Avalonia 11（C#/.NET）**（用户先询问"纯 Windows 场景推荐"，经对比后确认）
- 理由：Skia 自绘模型对高度自定义阅读器最顺手；长期维护稳定（独立 OSS + 商业背书）；免费覆盖 macOS/Linux；保留未来移动端出口（.NET 核心库可复用）；许可证 MIT 零风险
- 落选说明：WinUI 3（原生质感最佳但框架变动风险 + 无其他平台出口）；Flutter（移动端强但 Windows 系统集成弱）；MAUI/Qt/Tauri/Compose 不推荐
- 影响：见 docs/03-dev/conventions.md（工程结构按 Avalonia + .NET 定稿）

### D2 格式范围 ✅
- 选择：文件夹 + CBZ/ZIP（不强制 CBR/7z/PDF 进 V1）
- 影响：依赖最小（内置 ZipArchive + 文件夹遍历）；CBR/7z/PDF 作为 V2 扩展点，ComicSource 接口已预留

### D3 元数据 ✅
- 选择：V1 纯本地；V2 预留在线刮削接口
- 影响：无网络依赖；ComicInfo.xml 读写 + 文件名推断为 V1 实现范围

### D4 文件整理 ✅
- 选择：干跑预览 → 确认执行 → 操作日志可撤销
- 影响：FileManagerService 需实现"预览计划 + 执行 + 撤销"三段式；删除走回收站

### D5 进阶功能 ✅
- 选择：卷页动画/放大镜/跨页拆分/E-ink 等全部后置 M3
- 影响：M1 阅读器范围 = Pager + DoublePage + 缩放 + 翻页（点击/键盘/滚轮）+ 动画（无/淡入/滑动）+ 主题 + 续读

### D6 V1 范围 ✅
- 选择：确认 M1 = 流畅读日漫（RTL/双页/缩放/主题/续读）+ 基础库管理（文件夹+CBZ 扫描、封面墙、进度）
- 影响：进入 M0.5 技术 PoC（2–3 天）→ M1 编码；git init 待 D1 确定
