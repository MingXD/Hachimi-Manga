# 设置窗口 v2 总方案（Settings Dialog v2）

> 状态：**方案待用户检查确认**（未实施）。
> 用户决策（2026-08-23）：三组模式 + 通用组 = **四组分类**（通用 / 分页·左到右 / 分页·右到左 / 滚动）；
> 分页 ↑↓ 默认不要；组合键捕获（Ctrl+Shift+P）支持；右到左 下一页=Left,PgDn,Space、上一页=Right,PgUp。

## 一、要改的问题（v4 反馈）

1. 滑块无数值显示/无法输入数值
2. 无"恢复默认"
3. UI 粗糙
4. 快捷键编辑器：一个方块应绑一个键（或组合键）；多键分多个方块；分页按方向细分可分别设置；分类/布局混乱（横排三模式列 → 误解为冲突）
5. 录入快捷键时按键被吞/误触发（Space 激活按钮、↑↓/PgDn 触发滚动与焦点导航）

## 二、快捷键编辑器重设计（核心）

### 1) 四组分类：竖排四张卡片
```
┌─ 通用（所有模式共用）────────────────┐
│ 切换阅读模式  [M]              [+] │
│ 切换阅读方向  [D]              [+] │
│ 切换主题      [T]              [+] │
│ 跳页对话框    [G]              [+] │
│ 调试面板      [F12]            [+] │
│ 适应模式循环  [F]              [+] │
│ 复位          [R]              [+] │
│ 放大          [+]              [+] │
│ 缩小          [−]              [+] │
│ 预览栏开关    [P]              [+] │
└───────────────────────────────────┘
┌─ 分页 · 左到右 ────────────────────┐
│ 下一页   [Right] [PgDn] [Space] [+]
│ 上一页   [Left]  [PgUp]      [+]
└───────────────────────────────────┘
┌─ 分页 · 右到左 ────────────────────┐
│ 下一页   [Left] [PgDn] [Space] [+]
│ 上一页   [Right][PgUp]        [+]
└───────────────────────────────────┘
┌─ 滚动 ─────────────────────────────┐
│ 下一页整页跳 [Right] [PgDn] [Space] [+]
│ 上一页整页跳 [Left]  [PgUp]      [+]
│ 向下滑动一屏 [Down]             [+]
│ 向上滑动一屏 [Up]               [+]
└───────────────────────────────────┘
```
- **一个方块 = 一个键**（或一个组合键如 `Ctrl+Shift+P`）；**一个功能可绑多个键** = 一行多个方块。
- 操作：点击方块 = 捕获替换该键；右键方块 = 删除该键；行尾 `[+]` = 捕获并新增一个键。
- 通用组动作所有模式共用；模式组只放该模式特有动作。

### 3) 存储模型（settings.json）
```json
"Hotkeys": {
  "General":  { "ToggleMode": ["M"], "ToggleDirection": ["D"], "ToggleTheme": ["T"], "JumpDialog": ["G"], "DebugPanel": ["F12"], "CycleFit": ["F"], "ResetView": ["R"], "ZoomIn": ["OemPlus","Add"], "ZoomOut": ["OemMinus","Subtract"], "TogglePreview": ["P"] },
  "PagedLtr": { "NextPage": ["Right","PageDown","Space"], "PrevPage": ["Left","PageUp"] },
  "PagedRtl": { "NextPage": ["Left","PageDown","Space"], "PrevPage": ["Right","PageUp"] },
  "Webtoon":  { "WebtoonNextPage": ["Right","PageDown","Space"], "WebtoonPrevPage": ["Left","PageUp"], "WebtoonScrollDown": ["Down"], "WebtoonScrollUp": ["Up"] }
}
```
- 键 token 支持组合键：`Ctrl+Shift+P`（修饰键+主键）。

### 4) 分派（按键 → 功能）
- 按下键 → ① 查**当前模式组**（分页按当前方向选 PagedLtr/PagedRtl；滚动选 Webtoon）→ 命中执行；② 未命中查**通用组** → 命中执行；③ 都未命中 → 忽略。
- 组合键：同时匹配 KeyModifiers（Ctrl/Alt/Shift）与主键。
- 删除 DirNext/DirPrev 隐式语义键（改为显式分组）。

### 5) 冲突检测
- 编辑**通用**键：与通用 ∪ 三个模式组全部查重（通用键在所有模式生效）。
- 编辑**模式组**键：与通用 ∪ 该模式组查重（LTR 与 RTL 组允许同键 —— 不同时生效）。
- 冲突时提示并拒绝捕获。

### 6) 录入修复（按键不再误触发）
- 捕获期间焦点移到**中性提示元素**（无按钮/滚动条持焦）；
- 捕获走**窗口 Tunnel 阶段** KeyDown 并 `e.Handled=true`（先于一切控件处理）→ Space/Enter 不激活按钮、↑↓/PgDn 不滚动/不移焦；
- 纯修饰键（Ctrl/Alt/Shift 单独按下）不结束捕获，等主键组合；
- 读取器窗口是模态子窗不收到按键（Handled 双保险）。

## 三、其余改进

### A. 滑块 + 数值框 双向联动
- 每行 `[名称] [滑块] [数值框]`：拖滑块 → 数值框实时更新；数值框输入回车/失焦 → 滑块跳转（clamp 范围）。
- 整数项显整数（缓存页数/解码宽度），小数项显 1 位小数（基准/摩擦/甩动）。

### B. 恢复默认（每页独立）
- 底部按钮栏：`[恢复默认·阅读] [恢复默认·快捷键]  [保存] [取消] [打开介绍文件]`
- 各自只重置本页（不保存，等用户点保存）。

### C. UI 美化
- 宽度 720；分组圆角卡片 + 组标题；滑块行统一定宽对齐；快捷键方块统一小按钮样式（圆角/hover/捕获高亮）；页签/分隔线/留白统一（夜间深色风格）。

### D. 使用介绍页签不变
- usage.md 轻量渲染 + 打开文件按钮（已有）。
