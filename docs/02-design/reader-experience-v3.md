# 阅读器交互重构设计 v1（Windows 看图器逻辑）

> 状态：**已确认，实施中（见 docs/03-dev/experience-impl-plan.md）**。
> 参考：Windows 照片查看器 / ImageGlass / HoneyView（看图器交互）、CDisplayEx/YACReader（漫画阅读交互）。

## 0. 目标（用户需求）
1. **滚轮 = 以鼠标为焦点缩放，精细度高**（复刻看图器）
2. **拖拽移动图片**；图片可**拖出应用边界**（Windows 看图器行为）；按住**空白处不拖动**
3. **键盘 ←→ = 翻页**
4. 双页显示时**两张图默认严密贴合**（无中缝）
5. **上下无缝拼接模式（webtoon）+ 滚轮向下滚动**
6. （另见 library-hierarchy-files.md：层级库 + 文件操作）

## 1. 核心重构：ScrollViewer → 画布模型（Canvas Model）

### 为什么必须重构
当前用 ScrollViewer 承载图片，其 `Offset` 被限制在 `[0, 内容尺寸-视口尺寸]`：
- **无法实现"图片拖出应用边界"**（内容不能移出可视区）
- 缩放/平移受滚动范围约束，行为与看图器不一致

### 画布模型（看图器标准实现）
```
阅读区（Border, ClipToBounds=true）           ← 视口（窗口阅读区域）
  └── 图片层（Grid, 尺寸=内容实际尺寸）
        ├── 单页模式：1 张图
        ├── 双页模式：2 张图（Spacing=0 贴合，可选 gutter）
        └── Webtoon：垂直无缝拼接长列
      图片层变换：ScaleTransform(scale) + TranslateTransform(tx, ty)
```
- **状态**：`(scale, tx, ty)` —— **无边界限制**（图片可任意拖出视口）
- **缩放/平移 = 直接改变换**，与布局系统解耦，平滑且精细

## 2. 交互映射（复刻 Windows 看图器）

| 操作 | 行为 |
|---|---|
| **滚轮（无修饰键）** | **缩放**，以鼠标为焦点：`scale' = scale × 1.001^Δ`（精细、连续），焦点锚定 |
| Ctrl+滚轮 | 同样缩放（兼容旧习惯，可选） |
| **拖拽图片** | **平移**：`tx/ty` 随鼠标移动，**无 clamp → 可拖出应用边界** |
| 拖拽空白处 | **不响应**（hit test 只在图片上） |
| **← / →** | **翻页**（RTL：←=下一页，→=上一页；LTR 反之） |
| PageUp/PageDown/Space | 翻页（保留） |
| 双击图片 | 放大 100% ↔ 恢复 Fit（看图器习惯）【P1】 |
| 工具栏 +/− | 缩放（已有）；缩放滑杆（精细）【P1】 |

### 滚轮=缩放 vs 之前的"滚轮=翻页"
**以用户最新指示为准**：分页模式下滚轮=精细缩放，翻页交给键盘 ←→（及按钮）。
（P1 的 Webtoon 模式下滚轮=滚动，见 §4。）

## 3. 缩放与 Fit（精细、焦点锚定）
- **精细度**：`factor = 1.0015^Δ`（Δ=滚轮 tick），≈每格 1.5%，平滑；范围 2%–800%
- **焦点锚定**（鼠标位置不变点）：
  `tx' = mx - (mx - tx) × (scale'/scale)`，`ty'` 同理
- **Fit 模式**（FitWidth/FitHeight/FitScreen，初始与复位）：计算 `scale` 使内容适配视口，`tx/ty` 置中
- 打开书默认 FitWidth + 居中（保留现状）

## 4. 双页贴合 & Webtoon 拼接模式
### 双页贴合
- 双页时两图 **Spacing=0**（严密贴合，无中缝）——默认
- 提供"中缝宽度"设置（0/小/大）供需要留缝的用户【P2 设置项】

### Webtoon（上下无缝拼接）模式
- 阅读模式扩展：单页 / 双页 / **Webtoon**（M 键循环切换）
- 图片层 = **垂直拼接**所有页（或按需懒加载可见区），图片间无间隙
- **滚轮 = 滚动**（向下滚 → 内容上移）；缩放用 Ctrl+滚轮或按钮
- 记忆滚动位置；到达底部提示"已到末尾"
- 实现：Webtoon 模式下用"滚动偏移"（translate.y 控制），复用画布模型

## 5. 技术实现要点
- 移除 ScrollViewer 承载，阅读区 = `Border(ClipToBounds=true)` + 图片层（手动管理变换）
- 拖拽 hit test：`e.GetPosition(图片层)` 判断是否在图片内（空白=背景区域）
- 指针捕获（Pointer.Capture）确保拖拽期间不丢事件（headless 已验证 Capture 可用性——需再测）
- 缩放/平移直接操作 `RenderTransform`（ScaleTransform+TranslateTransform 组合，或用 MatrixTransform）
- 性能：平移/缩放实时响应（UI 线程直接改变换，无布局参与）；Webtoon 懒加载复用封面墙可见性计算思路
- 按需高清重解码（P1，放大超解码尺寸时重新解码）
