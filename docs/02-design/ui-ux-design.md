# UI/UX 设计（v1 — 结合商业/移动端 UX 调研）

> 核心参考：Perfect Viewer（11 种触控动作）、Mihon（点击区预设/每书设置）、Panels（预设系统/动态背景/单指缩放）、CDisplayEx（全快捷键自定义）、ComicRack（Workspaces/元数据驱动方向）、Foliate（主题选择器/减少动画）、YACReader（12 主题+编辑器）、Cover（RTL 对齐/窗口化）、Webtoon（手势-进度直映）。详见 ../01-research/commercial-ux.md。

## 1. 顶层结构
```
主窗口
├── 侧边栏：资料库 / 文件浏览器 / 最近阅读 / 收藏
├── 内容区：封面墙（虚拟化）或文件树
└── 顶栏：搜索、排序、视图切换、设置

阅读窗口（可全屏、可独立窗口）
├── 阅读区（Pager/DoublePage/Webtoon）
├── 悬浮顶栏：书名、页码、模式/方向/主题快捷切换
└── 底部进度条 + 翻页控件
```

## 2. 设置体系（差异化核心）
### 2.1 四层 + 预设
- 全局默认 → 系列级 → 单本 → 会话
- **命名预设系统**：保存/应用/导出/分享预设（如"日漫双页"、"Webtoon"、"夜间舒适"）——对标 Panels Standard/Dynamic/Immersive 预设
- 每层覆盖项：方向、模式、双页规则、中缝、缩放、动画、主题、翻页方式、封面规则

### 2.2 智能默认值（省心设计）
- 阅读方向：ComicInfo `<Manga>` → 文件名启发式 → 全局默认（Komga 自动推断）
- 宽窗口/横屏自动切双页（Panels）
- 双页默认：无缝中缝 + 按方向对齐（Cover 规则）
- 主题默认跟随系统

### 2.3 设置界面
- 分组：阅读 / 显示 / 库 / 文件管理 / 快捷键 / 高级
- **设置搜索**（Ctrl+F 过滤设置项）；每项显示当前生效层（来自哪层覆盖）
- 覆盖项带"恢复默认"与"跟随上层"两种状态

## 3. 主题
- 白天 / 黑夜 / 跟随系统 + 阅读区独立主题
- 夜间：UI 暗色 + 阅读区亮度/对比度/暖色滤镜（Mihon 软件亮度 -75~100、Kavita darkness）
- 主题选择器 + 自定义主题编辑器（YACReader 12 主题+编辑器思路）【V2】
- 动态/沉浸背景（Panels Dynamic/Immersive，背景色随封面变化）【V2】

## 4. 交互细节（Windows）
- 点击区预设 + 反相（Mihon）；全部快捷键可自定义（CDisplayEx）
- 滚轮缩放（以光标为中心）、拖拽平移、触屏捏合
- 拖放导入、右键菜单、资源管理器"用 MangaAgent 打开"
- 高 DPI、多显示器窗口记忆
- 翻页动画可关闭（无障碍）

## 5. 库界面
- 封面墙虚拟化（只渲染可见项）；网格/列表切换
- 视图：系列 / 单本 / 文件夹镜像三种
- **可保存的动态筛选**（Panels Filters：如"未读 + 2026 + 标签X"保存为收藏视图）
- 排序：最近阅读 / 标题 / 系列 / 添加时间 / 自定义
- 库详情页：封面、元数据编辑、单本设置入口、文件操作（重命名/整理/删除）

## 6. 无障碍
- 全键盘可达、可关动画、对比度主题、大字体
- 减少动画选项（Foliate）

## 7. 视觉语言
- 材料化但克制的桌面风格（非手机 app 感）；图标、间距、深色模式对比度经设计系统定义
- 启动画面 → 库界面 → 一键进入最近阅读
