# 需求文档（v1 — 结合调研精化，待用户评审）

> 本文档把用户设想 + 竞品调研（见 ../01-research/）提炼为可评审的需求。标注 [待定] 的项需用户拍板。

## 1. 产品定位
- **本地优先**的漫画阅读器：无账号、无在线源，数据全在用户磁盘
- Windows 桌面端为首要平台（V1）；未来 iOS/Android（V2，路径见技术选型）
- 差异化：**高度可定制阅读体验**（对标 Perfect Viewer / Panels 的自定义深度）+ **内置本地文件管理**（对标 Calibre 的整理能力）

## 2. 阅读体验（核心）
### 2.1 阅读方向
- 全局默认 + 每本书可覆盖：**RTL（日漫，默认）/ LTR / 竖排【待定】**
- 依据：ComicInfo.xml 的 `<Manga>` 字段优先，其次文件名/目录启发式推断，最后全局默认
- **方向与缩放正交**（竞品反面教材：KOReader 方向被缩放锁定变灰——我们绝不做）

### 2.2 页面模式
- 单页 / 双页 / 连续滚动（webtoon 垂直）
- 双页细节：
  - 封面默认单页，从第 2 页开始成对（可配置）
  - 跨页图（宽图 ≥ 阈值，可配置）：整张显示不裁切，可选分割线/中缝阴影
  - 双页中缝宽度可独立调节（Cover 用户痛点：不可调）
  - RTL 双页对齐规则（参照 Cover/Komga）：RTL 书首单页靠左、末单页靠右
  - 可选：横屏/宽窗口自动切双页（Panels 模式）
- 连续滚动：懒加载、滚动到章节边界预加载、点按翻页距离可配置

### 2.3 翻页与交互
- 翻页方式：点击区（左右/自定义分区）/ 键盘（←→、PageUp/Down、空格、音量键等）/ 滚轮 / 触摸滑动
- 点击区预设（参照 Mihon：Edge / L形 / 左右 / 禁用 + 可反相）
- 翻页动画：无 / 淡入 / 滑动 / 卷页【待定，成本高】；可关闭（无障碍）
- 缩放：适应宽度（默认）/ 适应高度 / 适应屏幕 / 原始尺寸；滚轮以光标为中心缩放；范围 25%–400%
- 平移：拖拽；放大时可禁用翻页防误触
- 放大镜（局部放大）【待定】

### 2.4 主题与视觉
- 白天 / 黑夜 / 跟随系统
- 夜间模式：UI 暗色 + 阅读区可配亮度/对比度/暖色滤镜（Mihon 软件亮度 -75~100、Kavita darkness level 参考）
- 自定义强调色【待定】；设置项搜索（对标商业软件）

### 2.5 进度与书签
- 自动续读（每本书记住：当前页、双页偏移、缩放、方向）
- 书签（逻辑页 + 备注【可选】）；"已读完"标记与筛选
- 系列流：读完一卷自动提示/跳到下一卷【待定】
- 阅读数据独立于文件，文件移动后按路径+修改时间重定位

### 2.6 设置分层（核心差异点）
- **全局默认 → 系列级 → 单本 → 会话** 四层 + **预设系统**（用户可保存/分享命名预设，如"日漫双页"）
- 每层覆盖项：方向、单/双页、中缝、缩放、动画、主题、翻页方式、封面规则

## 3. 本地漫画库
- 添加任意本地文件夹为资料库（多个库）
- 识别：文件夹即书 / 压缩包（CBZ/CBR）即书 / PDF【待定】
- 系列聚合：目录名 / ComicInfo Series 字段 / 文件名规则解析【可选】
- 扫描：全量 + 文件监听增量，后台执行不卡 UI
- 封面墙：虚拟化列表、缩略图三档缓存
- 搜索 / 排序 / 筛选（系列、卷、标签、状态、已读/未读）
- 元数据：ComicInfo.xml 读写（约 40 字段子集）、文件名推断；在线刮削（AniList/MAL）【待定】

**可撤销原则**：所有整理操作先干跑预览 → 确认执行 → 操作日志可撤销。

## 5. 非功能需求
- 5000 页 CBZ 随机翻页 <100ms；常驻内存可配置上限（默认 ≤512MB）
- 缩略图全库首扫后台；扫描可暂停恢复
- Windows：高 DPI、多显示器、拖放、资源管理器"用 MangaAgent 打开"、MSIX 自动更新
- 数据可迁移：库索引/进度导出 JSON；数据库可重建（文件是真相源）
- 日志与崩溃恢复（阅读进度防抖落盘）

## 6. 明确不做（V1）
- 在线源/爬虫、账号体系、云同步（本地优先）
- 移动端（V2 决策点见 tech-stack-eval.md 的"移动端路径取舍"）
- 图片编辑/标注【待定】
