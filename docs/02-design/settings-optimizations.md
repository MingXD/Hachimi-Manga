# 设置项优化调研与方案（Settings Optimizations）

> 状态：**方案待用户决策**（未实施）。
> 调研依据：mihon/Tachiyomi、YACReader、Kavita、Perfect Viewer 等阅读器的设置面；本应用现有设置项与交互习惯。

---

## 一、现有设置项可改进点

| # | 项 | 现状 | 建议 |
|---|---|---|---|
| 1 | 缩放/滚动速度 | "基准滑块(0.5~2) + 工具栏 ×0.5/1/2 按钮"双通道 | 双通道易困惑：按钮显示的倍率相对基准，用户可能以为按钮就是绝对值。**建议**：去掉工具栏 ×0.5/1/2 循环，只保留设置里的滑块（1 个值=实际速度）；或保留按钮但标签显示"实际值"（基准×档位），二者取一，避免混淆 |
| 2 | 高级项可发现性 | 解码宽度/缓存/甩动等平铺 | 归入"高级"折叠区（展开/收起），普通用户界面更清爽 |
| 3 | 损坏设置提示 | 加载失败静默默认 | 启动时若 settings.json 损坏 → 弹一次性提示（"设置文件损坏，已用默认值"），避免用户困惑 |
| 4 | 数值框输入体验 | 需手动清除再输入 | 聚焦即全选（SelectAll） |
| 5 | 设置窗口主题 | 固定深色 | 跟随阅读器白天/夜间主题（传 IsDark，卡片/文字换色） |
| 6 | 设置窗口尺寸 | 每次固定 720×580 | 记忆上次窗口尺寸/位置 |

## 二、新增设置项建议（按优先级）

### P1 阅读行为（打开书相关，用户最常调）
| 设置项 | 说明 | 默认 |
|---|---|---|
| 默认阅读模式 | 打开书且无保存状态时进入的模式（单页/双页/滚动） | 单页 |
| 恢复上次位置（续读） | 打开书是否跳到上次阅读页；关=总是从第 1 页 | 开 |
| 双击行为 | 放大/复位/无动作（原设计未选，可再提供） | 放大 |
| 双页配对起点 | 第 1 张起 / 第 2 张起（默认值，工具栏按钮仍可临时切） | 第 1 张起 |
| 默认适应模式 | 打开书默认视图：适应屏幕 / 适应宽度 | 适应屏幕 |

### P2 体验
| 设置项 | 说明 |
|---|---|
| 导出/导入设置 | 设置导出为 JSON 文件、导入恢复 —— 换机/给他人分享你的配置（结合 exe 旁 guide 分发很有用） |
| 全屏阅读 | 隐藏工具栏的全屏模式 + 快捷键（现有 F11 或自定义） |
| 预解码页数 | 翻页预取相邻页数（1/2/3，性能 vs 流畅） |

### P3 备选（可暂缓）
- 预览栏：自动隐藏延时、唤出热区宽度
- 缩略图清晰度（预览栏解码宽度）
- 转场动画开关（翻页淡入）

## 三、实施建议（待决策后执行）

3. 高级项折叠 + 损坏提示 + 数值框全选 + 设置窗口主题/尺寸记忆
