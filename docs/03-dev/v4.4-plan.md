# v4.4 方案设计：封面清晰度修复 + 文件夹封面尺寸调整

> 状态：**✅ 已实施（2026-12-24，v4.4）**——测试 132 → 138/138 全绿；变更见文末实施记录。

## 1. 封面清晰度问题（文件夹封面糊 + 横向封面偶尔糊）

### 根因（代码 + 数学确认）
封面统一用 `Bitmap.DecodeToWidth(源, 固定宽)` 解码，且显示控件是 `UniformToFill`（等比填满框、多余裁切）——**实际显示宽度取决于图片比例**：

```
UniformToFill 显示宽（能显示的源像素宽） = max(框宽, 框高 × 图片宽高比)
```

| 场景 | 框（当前） | 平均显示宽需求 | 实际解码宽 | 结果 |
|---|---|---|---|---|
| 漫画封面（纵向 0.7） | 216×309 | max(216, 309×0.7=216) | **260** | 略够 ✓ |
| 漫画封面（**横向 1.6+**） | 216×309 | max(216, 309×1.6≈**494**) | 260 | **明显糊** ✗（用户观察吻合） |
| 文件夹封面（纵向 0.7） | 216×232 | max(216, 232×0.7=162) | **(int)216** | 比漫画 260 还小 → **更糊** ✗ |
| 文件夹封面（横向 1.6） | 216×232 | max(216, 232×1.6≈**371**) | 216 | 糊 ✗ |

其他次要因素：
- 解码宽未乘 **DPI 缩放**（125%/150% 显示更糊）
- 缩略图缓存键仅 `path`：切换展示模式（大/中/小）后不重解码，宽度固定

### 修复方案
1. `ThumbnailService` 统一封面解码宽计算（新增 `CoverDecodeWidth`）：
   ```
   ratio = 图片实际宽高比（漫画=首页 GetPageSize 比例；文件夹封面=图片头 ParseHeader）
   fillW = max(框宽, 框高 × ratio)      // UniformToFill 需要覆盖的源像素宽
   decodeW = clamp(round(fillW × dpi × 1.25), 160, 1200)
   ```
2. `GetThumbnailAsync(book, coverW, coverH, dpi)` / `GetImageThumbAsync(path, coverW, coverH, dpi)` 接口升级；**缓存键改为 `path|decodeW`**（模式切换各自缓存，弱引用回收）
3. `WireEntry` 注入条目的封面框尺寸与 `dpi = 窗口 RenderScaling`（headless/无窗口 = 1.0）；`FolderEntryItemViewModel.LoadThumbnailAsync` 传对应框尺寸
4. 效果预估：大图模式封面解码宽 260 → **约 380–650**（取决于比例/DPI）；横向封面不再糊；文件夹封面与漫画封面清晰度持平
5. **顺带修复**（排查中发现）：`LoadVisibleThumbnails` 滚动懒加载的跳过条件是 `item.IsFolder` → **文件夹条目滚动后封面不加载**（只有前 24 条加载）。改为「文件夹无封面路径才跳过」
6. 测试：CoverDecodeWidth 纯函数单测（纵向/横向/DPI/钳位）；headless 封面缓存键含宽；既有测试回归

## 2. 文件夹封面尺寸调整（更接近漫画封面，上边距与左右边距一致）

### 现状
- 封面区 216×232，外层 StackPanel 垂直居中 → 封面离卡片顶部的空隙随文本行高浮动（用户看到"上方空间没利用完"）
- 宽 216 比卡片可用内容宽 228 小 → 左右各留 6，但**上下空隙不对称**

### 设计（按模式，宽=卡片内可用宽，顶部对齐）
| 模式 | 卡片 | 卡片内可用（扣 6×2 边距） | 文件夹封面区 | 漫画封面（对照） | 文本 3 行余量 |
|---|---|---|---|---|---|
| 大图 | 240×380 | 228×368 | **228 × 285** | 216×309 | 368-285=83 ≥ 文本≈77 ✓ |
| 中图 | 168×272 | 156×260 | **156 × 178** | 144×206 | 260-178=82 ≥ 76 ✓ |
| 小图 | 120×196 | 108×184 | **108 × 120** | 96×137 | 184-120=64 ≥ 58 ✓ |
| 详情 | — | — | 不显示 | — | — |

- 宽取满内宽（比漫画封面更"满"，左右边距 = 卡片边距 6px）
- 高比漫画封面矮 17–28px（给三行文本），比当前 232 **加高 53px**（大图），上方空隙消除
- 模板：文件夹 StackPanel 加 `VerticalAlignment="Top"`（上边距 = 左右边距 = 6px，与卡片边框一致）
- 封面 `UniformToFill` 裁切：竖图在 228×285 框中会上下各裁约 6%（可接受，居中裁切）
