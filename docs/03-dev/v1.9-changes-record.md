## 三、已知潜在风险点（用户检查时重点关注）

1. **物理页导航（A1）影响面最大**：翻页/进度条/书签/续读/模式切换/页码显示全部改了。若检查发现：
   - 双页翻页跳页异常 → 查 SetCurrentPhysical/LogicalIndexOfPhysical
   - 进度条拖动不准 → 查 OnJumpSliderValueChanged/SyncJumpSlider
   - 书签定位错 → 查 ToggleBookmark/NextBookmark（物理页语义）
   - 续读位置不对 → 查构造函数恢复逻辑
2. **平滑滚动+惯性（N2）**：滚轮行为完全重写。若发现：
   - 滚轮不动/乱动 → 查 ScrollWebtoonByEvent/StartSmoothScroll
   - 惯性滑过头 → 查 SmoothScrollTick 衰减系数
   - 键盘翻页异常 → 查 ScrollWebtoonPages
3. **主窗口 Grid 布局（U1）**：结构重写。若发现：
   - 侧栏/内容区错位 → 查 MainWindow.axaml Grid 列定义
   - GridSplitter 仍拖不动 → 查 GridSplitter 属性
4. **按钮样式（U2）**：若发现按钮文字颜色异常 → 查 Window.Styles Selector 与 VM 颜色属性
5. **缩略图栏（U3）**：若发现缩略图不显示/点击无效 → 查 ThumbEntry 绑定与 OnThumbnailClick
6. **封面墙展示切换（N1）**：若发现卡片尺寸异常/详情视图错乱 → 查 GalleryMode + WireEntry 尺寸
