# BUG-001：阅读器画面全空（能操作但看不到图） — 已修复 ✅

- **状态**：已修复并验证（2026-02）
- **优先级**：高

## 现象
双击打开漫画后，翻页等操作正常，但阅读区**看不到画面**（纯背景色）。

## 原因（调查确认）
1. 真实应用渲染/解码本身正常（夹具 PNG、2500×3500 JPEG、300 页书均验证渲染成功）。
2. **代码缺陷**：`ReaderViewModel.DecodeAsync` 每次翻页全尺寸解码且**无缓存、旧位图不释放**，
   解码异常被 try/catch **静默吞掉** → 在内存紧张机器（实测仅剩 ~2.7GB）上，大图翻几页后
   解码失败/内存累积 → Image1=null → **纯空白且无任何提示**。

## 修复
1. **页面位图 LRU 缓存（上限 6 页）**：翻页淘汰最旧页并 Dispose，控制内存峰值。
2. **解码失败可见**：失败时显示"无法解码第 N 页：<原因>"提示条，不再静默空白。
3. 补充诊断知识：Avalonia.Headless 平台 `Bitmap(Stream)` 一律解码为 1×1（测试伪影，
   非真实应用行为）——像素级验证一律用真实应用 `--open` + 截屏。

## 验证（实测）
- 夹具 CBZ / JPEG 大图 / 300 页书：真实应用截屏均正常渲染（light% 33.2 / 33.2 / 16.4）
- **内存稳定**：300 页书打开后连续采样 21s，WorkingSet 恒定 ~159MB（无泄漏、无累积）
- 测试 18/18 通过（新增：越过缓存上限逐页翻页不抛异常、无解码错误提示）

- 用户若仍空白：请提供其漫画格式/单页尺寸（已加失败提示，下次可见具体原因）
