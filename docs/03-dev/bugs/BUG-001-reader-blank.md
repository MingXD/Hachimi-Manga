# BUG-001：阅读器画面全空（能操作但看不到图） — 已修复 ✅

- **状态**：已修复并验证（2026-02）
- **优先级**：高

## 现象
双击打开漫画后，翻页等操作正常，但阅读区**看不到画面**（纯背景色）。

## 原因（调查确认）
1. 真实应用渲染/解码本身正常（夹具 PNG、2500×3500 JPEG、300 页书均验证渲染成功）。
2. **代码缺陷**：`ReaderViewModel.DecodeAsync` 每次翻页全尺寸解码且**无缓存、旧位图不释放**，
   解码异常被 try/catch **静默吞掉** → 在内存紧张机器（实测仅剩 ~2.7GB）上，大图翻几页后
   解码失败/内存累积 → Image1=null → **纯空白且无任何提示**。

## 修复（三轮）
第一轮（内存控制）：LRU 页面缓存 + 解码失败提示条。
第二轮（大图性能）：Bitmap.DecodeToWidth 按需降采样（4K 页 104MB→10MB）+ 翻页竞态防护 +
JPEG 头解析增强（64KB 缓冲）。
**第三轮（最终根因）**：`ReaderWindow.axaml` 两个 Image 补上 `Source="{Binding Image1/Image2}"`。

## 验证（实测）
第一轮：夹具/JPEG/300 页书渲染正常；内存稳定 ~159MB；18/18 测试通过。
**第二轮（用户真实文件 test-file：38 张 4299×6071 JPEG）**：解码性能已达标（内存 159MB）。
**第三轮（最终根因修复后，真实应用实测）**：
- 夹具书：阅读器窗口 light **0.4% → 82.6%**（页面内容显示）
- 用户真实书：阅读器窗口 light **28.3%**（页面内容显示），内存 159MB
- 测试 18/18 通过
