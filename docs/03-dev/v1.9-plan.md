## P0 严重 Bug（基础阅读功能）

### BUG-A 单页模式跳页（第一页直接到第三页）
**根因（已确认）**：PageLayouter 无论模式都按双页配对 (1,2)(3,4)… 生成逻辑页。单页模式 CurrentIndex 走逻辑页索引 → index1=(1,2) 显示物理第2页、index2=(3,4) 显示物理第4页 → **跳过物理第3页**。

**修复方案**：单页模式应逐物理页推进。
- 方案：引入「当前物理页」概念。逻辑页保留（双页用），单页模式导航 = 物理页 ±1；切模式时物理页不变、CurrentIndex 按新布局重算。
- 影响面：ReaderViewModel 导航（Next/Prev/Jump）+ 状态保存/恢复（改存物理页）+ 进度条映射。改动集中但涉及核心，需谨慎。

### BUG-B 缩放 >100% 时每次复位居中 + 不遵循鼠标焦点
**根因（已确认）**：内容宽（单页 ~533px）< 视口宽 1100px → 缩放后 ClampToViewportIfSmaller 检测「内容宽<视口」→ **强制水平居中** → 覆盖拖拽/锚定位置。

**修复方案**：缩放锚定后**不 clamp**（保留用户拖拽/焦点位置）；仅 Fit 模式初始居中。删掉 ZoomToFocus 里对 Custom 模式的 ClampToViewportIfSmaller 调用。

### BUG-C 添加资料库 G:\额外储存\bz_2 无反应（子目录可以）
**根因（已确认）**：AddLibraryAsync 的 try 块无 catch。bz_2 下层若有坏 ZIP/无权限目录/扫描中任何异常 → 异常传播出 async void → 静默失败（无反馈、库未添加）。子目录小且无坏文件所以成功。

**修复方案**：
- AddLibraryAsync/RescanAsync 加 try-catch + StatusText 错误提示
- LibraryScanner 内部容错：单个坏文件/目录 skip（不抛），进度回调已存在
- 加日志（SLog 记录扫描异常细节）

## P1 功能缺陷

### BUG-D 纯图片文件夹未显示为漫画（用户问题2）
**根因（已确认）**：ShowFolderContents 把 folder.Children 全部显示为文件夹条目，即使它是纯图片叶子（内部有 Books[0]）。

**修复方案**：子节点判定——有 Children（子文件夹）→ 文件夹条目；无 Children 但有 Books → 用 Books[0] 显示为**漫画条目**（封面/双击打开）；空 → 文件夹条目可进入。

### BUG-E 配对按钮在单页也显示
**根因**：当前 Single+Double 显示，Webtoon 隐藏。用户要求**仅 Double**。

**修复方案**：PairButton.IsVisible = (ViewMode==Double)。单页时隐藏且不影响（配对仅影响双页布局，单页本就单张显示——无需额外处理，隐藏按钮即可）。

### BUG-F 滚动模式进度条拖动无反应
**根因（已确认）**：Webtoon 下 JumpToPhysical 只改 CurrentIndex（逻辑页），视图 _ty 未滚动到新位置 → 漫画不动。

**修复方案**：Webtoon 跳页 → 视图按物理页前缀和计算 _ty 并滚动（ScrollToPhysical）。

### BUG-G 滚动模式缩放按钮：应屏幕中心为焦点，且附带上下移动
**根因**：按钮走 ZoomRelative → ZoomToFocus(ContentScreenRect().Center)。Webtoon 下 ContentScreenRect 是单页矩形 → 焦点错。

**修复方案**：Webtoon 模式缩放按钮/Ctrl 滚轮统一走 ZoomWebtoon，焦点 = 视口中心（按钮）或鼠标（Ctrl 滚轮）。

### BUG-H 滚动模式复位无效（期望：画面平移到当前页中央 + 缩放回默认）
**根因**：OnResetZoomClick 只设 FitMode=FitScreen → Webtoon 下无效果（Webtoon 忽略 FitMode）。

**修复方案**：Webtoon 复位 = _scale 回默认（宽度 50%）+ _ty 平移到当前可见页中央（不跳页）。

### BUG-I 滚动模式缩放后画面全黑（滚轮一动就恢复）
**根因（推断）**：ZoomToFocus（按钮路径）在 Webtoon 分支更新 PageLayer.Width/Height 但未正确重算虚拟化范围 → Canvas 内容被裁/偏移。Ctrl 滚轮走 ZoomWebtoon 正常。两条路径不一致。

**修复方案**：统一 Webtoon 缩放入口（都走 ZoomWebtoon），缩放后强制 UpdateWebtoonPages + Clamp。

## P2 UI/交互优化

### UI-1 左侧栏 GridSplitter 拖不动
**根因（推断）**：GridSplitter 在 DockPanel 中 Dock=Left，DockPanel 的 GridSplitter 需与相邻元素配合，且可能被 sidebar 固定 Width 限制。

**修复方案**：改为 Grid 两列（列宽可调），GridSplitter 放列边界（标准用法）。

### UI-2 白天模式按钮无边框 + 悬停文字变白看不清
**根因**：按钮 Foreground 绑 ForegroundHex（白天=深色），但 Fluent 默认样式悬停可能变白；按钮框不可见。

**修复方案**：统一按钮视觉——白天/夜间两套显式样式（背景/边框/悬停色），参考流行阅读器工具栏风格：扁平半透明按钮 + 悬停高亮；文字始终用 ForegroundHex。

### UI-3 两条进度条（删纯展示那条）+ 缩略图栏
**现状**：底部有可拖 JumpSlider（v1.8 加的）+ 原有 ProgressBar（纯展示）。

**方案（需调研）**：删 ProgressBar；底部做**缩略图预览栏**：
- 平时隐藏（悬停底部边缘或点按钮唤出）
- 显示当前页前后 N 张缩略图（复用 ThumbnailService 小图），点击跳转到对应页
- 与进度条联动：拖动进度条时显示缩略图
- 参考：KOReader Skim 对话框、Tachiyomi 进度缩略图
- 需讨论：缩略图栏触发方式、显示张数、是否常驻

## P3 增强功能

### 功能-1 封面墙显示大小切换（大/中/小）+ 详细视图
**方案**：
- 显示模式切换按钮（工具栏）：大图 / 中图 / 小图 / 列表（详细）
- 大中小：WrapPanel 卡片尺寸变化（如 240x330 / 184x262 / 120x170），文件夹/漫画同尺寸
- 详细视图：类似 Windows 资源管理器详情——行式列表（图标+名称+类型+页数+路径），无缩略图
- 需讨论：切换 UI（按钮/下拉/右键）、记忆上次选择、详细视图字段

### 功能-2 滚动平滑 + 惯性
**根因（已确认）**：滚轮按事件固定大步长（视口 40%），一格跳很远。

**方案（需调研成熟方案）**：
- 滚轮事件 → 目标位置累加（小步长），用动画/帧循环平滑过渡到目标
- 惯性：滚轮停止后按速度衰减继续滑动（可调：开关 + 强度系数）
- 速度按钮（已有 WebtoonSpeed）调节滚轮灵敏度
- 参考：浏览器/阅读器平滑滚动、Tachiyomi WebtoonRecyclerView fling
- 需讨论：惯性开关默认值、衰减曲线、动画帧率

### 功能-3 滚动默认宽度 50%
**根因**：当前等宽基准 = 进入时视口宽（100%）。

**修复方案**：WebtoonWidth = 视口宽 x 0.5（进入/切模式时）；缩放按钮仍可调。需确认。
